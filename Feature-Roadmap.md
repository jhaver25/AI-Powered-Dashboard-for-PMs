# AI-Powered Dashboard for PMs - Feature Roadmap

## Prioritized List
1. Storage for enabling trending information for specific projects and to allow for review of previous status updates
2. Ability to create 'Programs' to tie ongoing status updates together (needed for enabling trending properly across teams and programs)
3. Export to PPT / PDF for sharing with executives or using as an input into related presentations
4. JIRA API integration - retrieving specific ticket #'s and descriptions

## Other Ideas
- JIRA API integration - retrieving team-level velocity data to show productivity trends over time
- Model selection flag (e.g., Haiku for quick reads/drafts)
